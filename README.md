<h1>Food Unification</h1>

<p>Food Unification is a recipe and ingredient compatibility project for modpacks that use several farming and cooking mods. It connects matching ingredients and recipes, so the same kind of food item can be used across supported mods instead of having separate versions for everything.</p>

<p>For example, it aims to sort out duplicate ingredients like onions, flour and rice, and make recipes work across the food mods in your pack.</p>
